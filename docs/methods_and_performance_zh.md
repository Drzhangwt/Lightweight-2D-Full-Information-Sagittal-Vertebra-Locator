# 方法学与性能结果中文草稿

## 方法

### 研究任务

本研究构建了一个轻量化 2D 椎体中心点定位模型，用于从 3D CT 体数据中自动识别 T12-L5 椎体中心位置。该模型的主要应用场景是自动选择 L3 层面，以便后续进行腹部体成分分析；同时，模型保留 T12-L5 多椎体定位结果，可用于质量控制和未来功能拓展。

### 伪标签生成与数据清洗

首先基于 3D CT 体数据生成 T12-L5 椎体分割伪标签。对于每个病例，将椎体分割 mask 投影至矢状位平面，并以各椎体 mask 的质心作为对应椎体中心点标签。随后对生成的训练样本进行人工审核，剔除图像方向颠倒、解剖覆盖范围不足、仅包含上腹部、以及椎体伪标签明显错位的病例。

最终 clean 数据清单包括 935 个训练病例、186 个验证病例和 183 个测试病例。clean test 集共纳入 1,097 个 T12-L5 椎体中心点用于性能评价。

### 输入表示

每个 3D CT 体数据首先被重采样/重定向至标准空间。随后以估计的脊柱中心为中心，提取一个矢状位 slab，slab 半宽为 12 个体素。为了同时保留骨性结构和周围解剖信息，模型输入设计为 3 通道 2D 图像：

1. 软组织窗均值投影，窗宽范围为 `[-250, 500] HU`。
2. 宽 HU 范围最大密度投影，窗宽范围为 `[-1000, 1500] HU`。
3. 骨窗最大密度投影，窗宽范围为 `[150, 1200] HU`，并抑制低于骨窗下限的像素。

最终输入图像被缩放至 `384 x 256` 像素。

### 模型结构

模型采用轻量化 2D U-Net 风格编码器-解码器结构，包括 3 次下采样、转置卷积上采样、跳跃连接以及最终 `1 x 1` 卷积输出层。模型输入为 3 通道矢状位 slab 投影图像，输出为 6 个热图，分别对应 T12、L1、L2、L3、L4 和 L5 椎体中心点。

### 模型训练

训练目标为预测热图与高斯中心点标签热图之间的 masked mean squared error。对于扫描范围内不存在或标签缺失的椎体，不纳入损失计算。模型使用 Adam 优化器，初始学习率为 `0.001`，batch size 为 `8`，并使用 ReduceLROnPlateau 学习率调度策略。最终模型根据验证集 loss 选择最佳权重。

### 推理流程

推理阶段，模型首先输出 T12-L5 六个椎体的热图。每个椎体中心点由对应热图最大响应位置解码获得。随后将 2D 坐标映射回标准化 3D CT 空间。对于 L3，模型进一步根据预测中心点导出对应轴位 CT 单层图像，以供后续体成分分析使用。

### 评价指标

模型定位性能使用预测中心点与伪标签中心点之间的欧氏距离进行评价，单位为缩放后矢状位输入图像上的像素。成功检出率使用 SDR 指标表示：

`SDR@t = 定位误差小于等于 t 像素的椎体中心点数量 / 总椎体中心点数量`

本研究报告 SDR@5px、SDR@10px、SDR@15px 和 SDR@20px。

## 性能结果

在 clean test 集上，模型共评价 183 个病例、1,097 个椎体中心点。总体平均定位误差为 `2.85 px`，中位误差为 `1.00 px`。

| 指标 | 数值 |
| --- | ---: |
| 测试病例数 | 183 |
| 椎体中心点数 | 1,097 |
| 平均定位误差 | 2.85 px |
| 中位定位误差 | 1.00 px |
| SDR@5px | 92.07% |
| SDR@10px | 93.16% |
| SDR@15px | 93.80% |
| SDR@20px | 94.53% |

分椎体性能如下：

| 椎体 | 平均误差(px) | 中位误差(px) | SDR@5px | SDR@10px | SDR@15px | SDR@20px |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| T12 | 3.09 | 1.00 | 90.71% | 92.35% | 92.35% | 93.44% |
| L1 | 4.16 | 1.00 | 89.07% | 89.62% | 90.16% | 90.16% |
| L2 | 3.91 | 1.00 | 88.52% | 89.07% | 89.62% | 90.71% |
| L3 | 3.00 | 1.00 | 91.26% | 92.35% | 93.44% | 93.99% |
| L4 | 1.56 | 1.00 | 95.08% | 97.81% | 98.91% | 99.45% |
| L5 | 1.39 | 1.00 | 97.80% | 97.80% | 98.35% | 99.45% |

其中 L3 的 SDR@10px 为 `92.35%`，说明该轻量模型能够较稳定地完成 L3 层面定位，适合作为自动化 L3 层面选择与后续体成分分析流程的前置模块。
